# lol_yasuo_kr — 야스오 (League of Legends, 한국어)

리그 오브 레전드 야스오의 한국어 음성을 [CESP v1.0](https://openpeon.com) 이벤트 카테고리에 맞춰 묶은 사운드 팩입니다.

## 설치

```bash
peon packs install lol_yasuo_kr
peon packs use lol_yasuo_kr
```

## 카테고리별 음성

### `session.start` (세션 시작)

| 파일 | 대사 |
|------|------|
| `sounds/YasuoStoryNotOver_KR.wav` | 이야긴 아직 끝나지 않았어. |
| `sounds/YasuoWandererNotLost_KR.wav` | 방랑자라고 길을 잃은 건 아니지. |
| `sounds/YasuoMyFate_KR.wav` | 내 운명은 내가 정해. |

### `task.acknowledge` (작업 수락)

| 파일 | 대사 |
|------|------|
| `sounds/YasuoToTheEnd_KR.wav` | 이 길 끝까지 간다. |
| `sounds/YasuoOneStepAhead_KR.wav` | 과거보다 한 발 앞서 나간다. |
| `sounds/YasuoFollowTheWind_KR.wav` | 바람을 따르되 뒤를 조심해라. |
| `sounds/YasuoNoMoreRunning_KR.wav` | 더 이상 도망치지 않는다. |

### `task.complete` (작업 완료)

| 파일 | 대사 |
|------|------|
| `sounds/YasuoSwordFirst_KR.wav` | 검이 최우선이지. |
| `sounds/YasuoNeverGetsOld_KR.wav` | 싸움은 해도 해도 질리질 않는다니까. |
| `sounds/YasuoNotBad_KR.wav` | 그럴싸한데. |

### `task.error` (오류)

| 파일 | 대사 |
|------|------|
| `sounds/YasuoOneMistake_KR.wav` | 한 번 실수하면 그걸로 끝이다. |
| `sounds/YasuoQuickRuin_KR.wav` | 사람 하나 망가지는 거 순식간이지. |
| `sounds/YasuoNotYet_KR.wav` | 아직 죽긴 이르다. |

### `input.required` (입력 대기)

| 파일 | 대사 |
|------|------|
| `sounds/YasuoWhoTaughtYou_KR.wav` | 누구한테 배운 거지? |
| `sounds/YasuoWait_KR.wav` | 잠깐... |
| `sounds/YasuoBroughtFriends_KR.wav` | 친구들은 좀 데려왔겠지? |

### `resource.limit` (한도 도달)

| 파일 | 대사 |
|------|------|
| `sounds/YasuoHeavySword_KR.wav` | 이 칼, 정말 지겹도록 무겁군. |

### `user.spam` (연타)

|------|------|
